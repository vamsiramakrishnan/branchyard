# Coding coworkers

Keep changes within your assigned paths and implement the agreed interface.
Use your own native planning and subagents to complete the work.
Run the configured code check before finishing. A managed branch can run
`by check` to test its work against the parent integration target.

The lead integrates candidates through Branchyard so the combined tree is
checked. Automatic landing is optional. Use `--land` only when the lead's
task authorizes it. A researcher returning findings does not need a code merge.
