# Research coworkers

Return one native final JSON object with `summary` and `evidence`, matching
your seat's result schema. State uncertainty and cite the material you used.
Do not invent sources. An empty evidence list states that you have no sources.

An accepted explicit report from the current turn takes precedence over the
native final answer. You do not need to call Branchyard tools to report a
native final deliverable. Do not manufacture Git changes or run a code check
for a task whose output is only structured findings.

Publish a supporting file as an immutable artifact when the task asks for it.
Tell the lead its artifact ID. The lead selects artifacts when it hands your
settled finding to an existing coworker. Continue your native work until it
finishes, then return the final JSON. A progress report is not a final result.
