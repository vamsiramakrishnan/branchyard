# Evidence and analysis

Capture sources, extract tables, clean data, calculate and verify claims.

[All topics](../../INDEX.md)

- [source-capture](../../source-capture/INDEX.md): Snapshot retrieved local sources with origin metadata, exact hashes and page, paragraph or cell anchors for later evidence checks.
- [table-extract](../../table-extract/INDEX.md): Extract local PDF, DOCX and XLSX tables into reviewable records with source hashes and page, table or sheet locations.
- [data-clean](../../data-clean/INDEX.md): Normalize local CSV data with explicit trim, null, type and duplicate policies while preserving identifiers and recording changes.
- [calculate](../../calculate/INDEX.md): Evaluate reproducible arithmetic with named quantities, explicit units and assumptions using Pint, recording inputs and results.
- [claim-verify](../../claim-verify/INDEX.md): Check source hashes, reproduced extraction anchors and exact quotations while keeping factual support and semantic review explicit.
- [inspect-layout](../../inspect-layout/INDEX.md): Render document pages and presentation slides into inspectable previews, keeping rendering distinct from visual review.
