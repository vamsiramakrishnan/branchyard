# Design

Compose readable pages, truthful charts and editable diagrams.

[All topics](../../INDEX.md)

- [visual-design](../../visual-design/INDEX.md): Apply coherent visual hierarchy, typography, spacing and color to reports, presentations and other knowledge artifacts.
- [chart-design](../../chart-design/INDEX.md): Choose truthful chart encodings with explicit units, uncertainty and source data, using editable charts where supported.
- [diagram-design](../../diagram-design/INDEX.md): Create editable process, relationship and system diagrams using Mermaid or established drawing tools.
