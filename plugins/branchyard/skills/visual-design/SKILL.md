# Design a knowledge artifact

Establish the audience, medium, required template and primary message. Reuse supplied brand assets and templates. Read [composition guidance](references/composition.md) when choosing a visual system.

Define page dimensions, margins, typography, colors and spacing. Share that specification before parallel workers draft sections. Use existing DOCX styles or the deck design object consistently. Start with the installed DOCX or deck examples through artifact-tools; preserve editable text, tables and charts.

Use hierarchy and emphasis to make evidence readable. Render representative layouts early, including the longest title and densest table. Inspect all final pages with inspect-layout. A design specification is an input; actual rendered output is the evidence.
