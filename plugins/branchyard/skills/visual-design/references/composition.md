# Composition decisions

Adapted from Anthropic's Apache-2.0 canvas-design skill. Changes: a concise guide to document and slide composition; art-manifesto workflow, bundled fonts and output restrictions omitted.

Choose a consistent relationship between space, form, color and typography. Give the reader a clear entry point and a deliberate path through the page. Let scale and grouping communicate hierarchy.

Express that system through a small set of reusable layouts and design values. Preserve meaningful whitespace, align related elements, and use emphasis selectively. Reuse the user's template and supplied brand assets.

Document and slide work also needs editable content, accurate evidence and legible dense pages. Test the longest title and densest table with actual fonts before applying a layout to all sections.

For an executable starting point use the installed deck.json and section.json with the deck assemble command, or docx.json with docx create. Native document APIs remain available for templates beyond the convenience renderer's scope.
